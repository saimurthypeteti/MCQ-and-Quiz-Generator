# User guide

1. Upload a supported PDF, DOCX or TXT, or paste a passage. TXT works without extra packages; PDF and DOCX readers are optional dependencies.
2. Preview the extracted text. Scanned PDFs with little extractable text need OCR before generation.
3. Generate questions from an uploaded source or pasted passage. Choose count, difficulty, question type, and MCQ option count.
4. Review and edit each question, answer, explanation, and source excerpt. The baseline's distractors are deliberately marked for review.
5. Save a draft to continue later or approve/publish after review.
6. Use Take from the quiz library, answer each question, and submit. The server calculates and persists the score; results show unanswered items and explanations.
7. Open Evaluation to inspect calculated metrics and definitions. Empty metrics mean no quiz data has been saved yet.
